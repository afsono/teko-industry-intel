# 五种输出形态的完整模板

> 取到数据后怎么讲——这决定用户觉得"有用"还是"又一份新闻列表"。
> **模板是骨架，不是填空。** 每条内容都要先判断"这条对这类用户的决策意味着什么"。

---

## 形态一：速览（5 条，一句话）

**何时用**：用户说"今天有什么大事""快速看一下""有什么值得关注的"，或意图不明时的默认输出。

```
## 今日速览 · 10 月 26 日

1. **美国拟扩大对华投资管制**（G05 · 73 分）
   在半导体、AI、量子基础上新增超算、高超声速、生物技术，中方明确反对。

2. **谷歌云营收增 82%，Gemini 用户 9.5 亿**（I451002 · 81 分）
   AI 投入开始兑现，云业务成为增长主引擎。

3. ...

> 数据来自 tekoai.net，每条可点原文核验。
```

**纪律**：
- 一句话说清「谁做了什么 + 意味着什么」，≤40 字
- 必须带编号和评分（让用户知道为什么选它）
- 不给 5 条就凑 5 条——只有 3 条过线就给 3 条

---

## 形态二：标准简报（15 条，分板块）

**何时用**：用户说"来份日报""详细说说""帮我整理一份"。

```
## 产业情报简报 · 2026-10-26

**覆盖**：信息技术 12 条 · 能源 5 条 · 宏观 8 条（≥45 分，滚动 24h）

### 信息技术 · 45 条

**[81] 谷歌云营收增 82%，Gemini 用户达 9.5 亿**
Alphabet 战略 AI 投资见效，Google Cloud 营收激增 82%……
`I451002 互联网服务与基础设施` · Alphabet · 17 小时前
→ 值得关注：AI 投入进入兑现期，云厂商竞争重心从"投多少"转向"赚多少"
[原文](https://...)

**[78] 三星电子 HBM4 量产**
...

### 能源 · 8 条
...
```

**每条四要素**（缺一不可）：
1. **评分 + 标题**
2. **摘要**（来自数据源，原样使用）
3. **分类 + 主体 + 时间**
4. **一句"值得关注"**（这是二次加工，需标注）

## 形态三：单条深挖（五段结构）

**何时用**：用户说"第 3 条展开""这条细说"。

```
### [81] 谷歌云营收增 82%，Gemini 用户达 9.5 亿

**发生了什么**
Alphabet 三季度财报显示，Google Cloud 营收同比增长 82%，
生成式 AI 产品 Gemini 用户数达 9.5 亿。

**关键信息**
- 云业务增速（82%）远超公司整体
- Gemini 用户规模（9.5 亿）进入第一梯队
- 分类：I451002 互联网服务与基础设施 · 评分 81（S 级）

**背景上下文**
（基于数据源与联网补充，标注来源）

**潜在影响**
（明确标注为"推断"，并给出推翻条件）

**后续可关注**
- 下一个观测点：Gemini 的商业化转化率是否跟上用户增长
- 反向信号：如果云增速回落到 40% 以下，说明 AI 投入未形成持续拉动力
```

**纪律**：`潜在影响` 段必须显式标注是推断；要有"如果 X 发生则这个判断不成立"的反向条件。

## 形态四：增量（只讲新增）

**何时用**：用户说"跟上次比有什么新东西""有什么更新"。

```
## 相较上次（10-26 09:30）新增 7 条

**新出现的主体**：三星电子（HBM4 量产）
**评分上升**：（本数据源不提供历史评分，此项无法给）
**首次进入视野的赛道**：T013 核电与可控核聚变

新增条目：
- [74] 力积电三季度净利润翻倍（I453003）
- [70] 美拟扩大对华投资管制（G05）
...
```

**纪律**：`--since-last` 依赖 `memory/pushed.jsonl` 流水。
首次使用没有基线，要如实说明"这是首次运行，无法对比"。

## 形态五：可分享 HTML 日报

**何时用**：用户要存档、转发、发群里。

```bash
python scripts/intel.py --sector 信息技术 --persona analyst --format json > d.json
python scripts/render.py --input d.json --out brief.html \
  --title "信息技术板块日报" \
  --subtitle "面向行业研究人员：结构化分类 + 可追溯编号" \
  --persona analyst --group-by sector
```

产物是**自包含单文件 HTML**：无外部 CSS/JS/字体，可直接邮件附件、微信发送、长期归档。
深色 Vercel 风格，每条带评分色标、分类标签、地理落点、原文链接。

`--group-by` 可选 `sector` / `channel` / `cat_code`，按用户关心的维度分组。

## 五类画像的差异化输出

### 政策制定者

多一段**传导链**：

```
【事件】美财政部发布新版对外投资限制拟议规则，新增超算、高超声速、生物技术
【传导】投资限制 → 中美相关领域跨境资本流动收紧 → 国内相关企业海外融资与
        技术合作受阻 → 国产替代需求上升（第 3 跳属推断）
【时间窗】拟议规则，处于征求意见阶段，通常是 30–60 天
【不确定性】具体清单范围未定，需等待最终文本
```

### 企业决策者

按**动作类型**分组（产能投资/产品技术/市场渠道/资本动作/人事组织），
每条末尾加"对我意味着什么"。

### 个体投资者

强制三分：**事实 / 叙事 / 推断**，并给"值得关注"与"需要警惕"两栏。
每条输出必须带免责声明。

### 行业研究人员

用**表格**，保留全部字段，不删条目：

| 编号 | 分类 | 标题 | 评分 | 来源 | 时间 |
|---|---|---|---|---|---|
| I451002 | 互联网服务 | 谷歌云营收增82% | 81 | Crypto Briefing | 10-25 17:00 |

### 科研人员

按**技术成熟度**分层（原理验证 / 中试样机 / 小批量量产 / 规模量产），
每条标注"距产业化还差什么"。

## 反面模式（看到就要改）

| 反面写法 | 问题 | 正确做法 |
|---|---|---|
| "据不完全统计，近期科技股普遍上涨" | 无来源、无法核验 | 给具体条目 + 原文链接 |
| "分析师认为该赛道将迎来爆发" | 假托权威 | 不说"分析师认为"，要么给真实来源，要么标"我的推断" |
| "这 15 条是最重要的" | 未说明筛选依据 | "按评分排序，≥50 分共 15 条" |
| 摘要自己重写得更"通顺" | 篡改原始信息 | 原样用，或标注"二次浓缩" |
| 10 条里 6 条是同一事件的不同报道 | 重复占位 | 去重后保留最高分那条 |
| 把 40 分条目说成"重要" | 夸大 | 如实说"边缘过线，影响范围有限" |
