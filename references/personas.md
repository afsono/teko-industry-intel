# 五类用户：需求痛点、使用场景、取数口径、输出设计

> 同一个数据源，五类人问的问题完全不同。
> **先判断用户是哪一类，再决定取什么、怎么讲。**
> 判断错，输出就会答非所问——给投资者讲政策文本，给科研人员讲股价，都是浪费。

---

## 判定表：三句话内识别用户类型

| 用户这样说 | 判为 | 依据 |
|---|---|---|
| "这个政策对我们行业影响多大" / "我们要不要做 XX 规划" / "上级要一份 XX 产业的判断" | **政策制定者** | 关心"传导链"与"可操作窗口"，而非单点事件 |
| "竞争对手最近在干什么" / "这个市场能不能进" / "供应链有没有风险" / "我们要不要布局 XX" | **企业决策者** | 关心自己的相对位置 |
| "这些板块哪个能买" / "有什么催化剂" / "现在追高吗" / "帮我盯盘" | **个体投资者** | 关心可交易的时点 |
| "给我一份 XX 产业的图谱" / "这个赛道格局怎样" / "哪几家在做" / "数据要能追溯" | **行业研究人员** | 关心结构与可比口径 |
| "这个方向的技术进展" / "产业化到哪一步了" / "有没有政策或资金支持" | **科研人员** | 关心技术成熟度与转化路径 |

**判断不出时**：按「速览」给一版（成本最低、最容易被纠正），并问一句
"你更关心**能做什么决策**，还是**发生了什么**？"——这句话能一步分开四类人。

**允许一人多画像**："我是投资人，但也写行业报告" → 主画像 investor，输出时加一栏结构化分类。

---

## 一、政策制定者 / Policymaker

### 痛点
1. **信息过载但缺少传导链**：知道"美国加关税了"，不知道"对我省哪几个行业、多久见效、哪个环节先受影响"。
2. **时点难把握**：政策窗口期短，等报告出来已经错过征求意见阶段。
3. **口径不一致**：不同来源说的"产业规模"不是一个口径，没法写进文件。

### 典型场景
- 上级要求三天内出一份「某产业外部环境变化及应对」的判断
- 某国出台出口管制，需要评估对本地产业链的影响环节
- 需要跟踪某类政策（补贴/准入/标准）在本月是否有新增

### 取数口径
- **起点：宏观频道** `--macro G05,G06,G08,G13,G14`（贸易/地缘/产业政策/气候/科技治理）
- **终点：落到具体板块** `--sector <受影响板块>`，形成"政策 → 板块 → 行业"链路
- 评分门槛提高到 **55**
- 优先看 `keywords` 里同时出现「政策主体」与「产业环节」的条目

### 输出设计
**必须给出传导链，不是罗列新闻。**

```
【事件】一句话说清谁做了什么、生效时间
【传导】政策 → 直接受影响环节 → 次生影响（2-3 跳，每跳一句）
【时间窗】现在处于什么阶段（征求意见/已生效/过渡期），还剩多久
【不确定性】哪一环的判断最没把握，需要补什么信息
【可核验】原文链接 + 评分
```

**禁区**：不评价政策好坏，不预测"政府会怎么做"（那是编造），
只讲**已发生的事实**与**可推理的影响环节**，并标明哪部分是推理。

## 二、企业决策者 / Executive

### 痛点
1. **竞品动态散落在几十个源**，等看到时对手已经签完合同。
2. **看不清自己是"领先还是落后"**：单条新闻看不出相对位置。
3. **供应链风险被动发现**：上游出事才知道自己依赖它。

### 典型场景
- 季度战略会前，需要"主要对手最近在做什么"
- 评估新市场进入：那个市场的外部条件变了吗
- 上游关键材料/零部件是否有断供信号

### 取数口径
- **主用赛道频道** `--track T001,T006,T009`（对手通常按赛道活动，不按板块）
- **辅以板块** `--sector <自身板块>`，看同板块其他玩家的动作
- **主体追踪** `--keyword <对手名>,<英文名>,<品牌>` —— 这是最有价值的一步
- 评分门槛 **50**

### 输出设计
**按「动作类型」分组，而不是按时间。** 决策者要的是"对手在干什么"的分类视图：

| 动作类型 | 看什么 |
|---|---|
| **产能与投资** | 建厂、扩产、并购、合资 |
| **产品与技术** | 新品、认证、专利、良率突破 |
| **市场与渠道** | 进入新国家、签大客户、渠道合作 |
| **资本动作** | 融资、IPO、财报超预期/暴雷 |
| **人事与组织** | 高管变动、裁员、重组 |

每组 1-3 条，**每条末尾加一句"对我意味着什么"**（明确标注是推理）。

**禁区**：不给"建议收购/建议进入"这类战略结论，只给**可观察的动作**与**需要自己验证的假设**。

## 三、个体投资者 / Investor

### 痛点
1. **噪音太多**：99% 的新闻对持仓毫无影响，但都写得很像大事。
2. **追高被套**：看到"某某赛道爆发"时行情已经走完一半。
3. **分不清"事实"与"叙事"**：媒体标题的措辞往往比事实激进。

### 典型场景
- 早上看盘前，需要 10 分钟知道昨夜发生了什么、影响哪些板块
- 持仓某个赛道，想确认"逻辑还在不在"
- 想找"还没被充分定价"的方向（而不是已经涨完的）

### 取数口径
- **板块轮动** `--macro G02,G04,G11 --sector <持仓板块>`
- **催化与风险** `--top --persona investor`（门槛 45）
- **热度验证**：看同一赛道当天有几条 ≥40 分新闻——**条数本身就是热度信号**
- **地理分布**：看 `place` 字段集中在哪些国家，判断风险敞口

### 输出设计
**必须做"事实 / 叙事 / 我的推断"三分。**

```
【事实】可核验的硬信息（数字、时间、主体）
【叙事】媒体或市场的解读口径（标明这是叙事，不是事实）
【推断】我的判断（显式标注"推断"，并给出推翻条件）
```

同时给两栏：
- **值得关注**（有新增硬信息）
- **需要警惕**（叙事过热但事实支撑不足——这是最有价值的提醒）

**禁区（铁律）**：
- ❌ 不给买卖建议、不给目标价、不说"建议加仓/减仓"
- ❌ 不把评分当投资价值——**评分衡量的是新闻重要性，不是标的收益率**
- ❌ 不预测涨跌
- ✅ 可以做的是：把事实与叙事分开、指出信息缺口、提示风险

**必须每次声明**：
> 评分是对新闻重要性的判断，不代表任何标的的投资价值。以下为信息整理，非投资建议。

## 四、行业研究人员 / Analyst

### 痛点
1. **缺少可比的分类口径**：不同报告对"新能源"的定义差三倍，没法横向比。
2. **数据不可追溯**：引用一条结论，找不到原始出处。
3. **只能看到"现在"，看不到"演变"**：需要事件序列，而不是快照。

### 典型场景
- 写某赛道的行业研究报告，需要"近 24h 该赛道的全部重要事件"
- 做产业链图谱，需要按行业编号归类
- 分析某事件的演化，需要时间序列

### 取数口径
- **用编号体系**：`--track T001` / `--sector 信息技术` / `--macro G06`
- **一定要带编号输出**：`cat_code`（I/T/G）+ `cat_name` + `sector`
- 评分门槛 **40**（研究者要全，不要精选）
- 需要"全集"时用 `--format json`，自己二次分析

### 输出设计
**按分类编号分组，保留全部可追溯字段。**

```
| 编号 | 分类 | 标题 | 评分 | 来源 | 时间 | 原文 |
```
- **不删条目**：低分的也保留（研究者需要看到"没有大事"这个事实本身）
- **标注口径**：说明这是"滚动 24 小时、≥40 分、已过滤娱乐体育"的样本
- **说明局限**：`score` 是模型判断，分类是单标签，跨类目事件会被归到一个主类

**禁区**：不要为了"好看"删掉低分条目——研究者最恨被替他们做筛选。

## 五、科研人员 / Researcher

### 痛点
1. **技术新闻与产业化脱节**：论文说"效率提升 30%"，但不知道离量产还有多远。
2. **不知道谁在做**：技术方向清楚了，但不知道哪些机构/公司在推进。
3. **政策与资金信号分散**：想找资助方向、合作机会，得翻很多源。

### 典型场景
- 写项目申报书，需要"该方向的国际进展与产业需求"
- 找合作方：这个技术谁在做、做到什么程度
- 判断选题的产业价值：这个方向有没有真实需求

### 取数口径
- **技术突破**：`--sector <相关板块> --keyword <技术名中英>`
- **产业化信号**：`--track T001,T013,T017`（找到"从实验室走向产线"的事件）
- **政策与资金**：`--macro G08,G14,G03`
- 评分门槛 **50**（要少而准，不要刷屏）

### 输出设计
**按「技术成熟度」分层，而不是按热度。**

| 层 | 特征 | 该看什么 |
|---|---|---|
| **原理验证** | 论文、实验室数据 | 效率/指标突破、可重复性 |
| **中试/样机** | 试验线、样机、认证 | 良率、成本、稳定性 |
| **小批量量产** | 首条产线、首批订单 | 客户是谁、产能多少 |
| **规模量产** | 扩产、降价、份额 | 成本曲线、替代关系 |

每条标注所属层，并给"距产业化还差什么"（一句，标注为推断）。

**禁区**：不把"宣称突破"当"已实现"；不省略样本量与测试条件（源文没有就明说"未提及"）。

## 通用：跨画像的输出纪律

无论哪类用户，以下六条不变：

| 纪律 | 说明 |
|---|---|
| **评分必须显示** | 每条都带 0-100 分，让用户知道"为什么选它" |
| **原文必须可点** | 每条带原文链接，用户能自己核验 |
| **摘要不重写** | 摘要来自数据源，原样使用；要浓缩就标注"二次浓缩" |
| **不凑数** | 要 15 条只有 9 条过线，就给 9 条并说明 |
| **DUP 必删** | `score_class == DUP` 是重复项 |
| **推断要标注** | 事实 / 叙事 / 推断三者不能混 |

**每次输出末尾固定加一行来源说明**（用户可核验，也是合规要求）：

> 数据来自 tekoai.net：每日由前沿大模型处理 10 万条以上原始资讯（20 余种语言、上万个信息源），
> 完成去重、评分与产业归类后仅保留高分结果。每条的评分与分类为模型判断，事实请以原文为准。
