# 全球头条精选 · teko-industry-intel

[English](README.md) · [站点](https://tekoai.net) · [博客](https://tekoai.net/zh/blog/)

> 不是把新闻堆给你，而是回答：**这个产业今天发生了什么、哪几条真正影响你的决策、为什么。**

面向五类决策者，从每日约 **2.6 万条**原始资讯、经前沿大模型评分筛选后的情报里，
挑出真正值得看的，附 **0–100 评分**、**分类编号**、**地理落点**与**原文链接**。

---

## 它和市面上的新闻 skill 有什么不同

| 常见做法 | 这个技能 |
|---|---|
| 抓标题堆给你，相关性 40–60% | **大模型逐条评分筛选**，只给过线的 |
| 全网热搜、大众舆情视角 | **产业与决策视角**（板块、赛道、政策传导） |
| 只覆盖 AI 或财经单一领域 | **8 板块 + 12 赛道 + 16 宏观频道**，可任意组合 |
| 给你列表，不告诉你为什么选它 | 每条带 **0–100 评分**、**242 编号分类**、**原文链接**，可核验 |
| 分不清事实与观点 | **事实 / 叙事 / 推断** 三分，推断必标注 |
| 一套输出打天下 | **五类画像各给一套**：政策传导链 / 竞品动作分类 / 投资三分 / 研究表格 / 技术成熟度 |

### 数据来源与可信度

数据来自 **tekoai.net**：

- 每日由前沿大模型处理约 **2.6 万条**原始资讯，覆盖 **20 余种语言**、**5,000 余个采集源**
- 每条经过去重、评分、产业归类，**只保留高分结果**
- 分类体系 **242 个编号**：174 个行业（沿用 GICS × 申万三级）+ 52 个热门赛道 + 16 个通用类目
- 约 **79%** 条目带经纬度，映射到机构/总部/城市
- **每小时刷新**，静态 JSON，无需 API key，国内可直连

> 所以它和"抓一堆标题"的工具不同：每一条都带着**为什么入选**的信号，
> 以及可以点开核验的**原文链接**。

## 五类用户，五套答案

同一个数据源，五类人问的问题完全不同。这个技能**先判断你是谁，再决定怎么讲**。

### 一、政策制定者

**痛**：信息过载但缺传导链；知道"加关税了"，不知道"影响我这儿哪几个行业、多久见效"。

**给你**：政策 → 直接受影响环节 → 次生影响（每跳一句）+ 时间窗 + 不确定性。
哪一跳是推断会标出来。不评价政策好坏，不预测政策走向。

```bash
python scripts/intel.py --persona policymaker --macro G05,G06,G08 --limit 15
```

### 二、企业决策者

**痛**：竞品动态散在几十个源；看不清自己是领先还是落后；供应链出事才知道依赖它。

**给你**：按**动作类型**分组——产能投资 / 产品技术 / 市场渠道 / 资本动作 / 人事组织，
每条末尾一句"对我意味着什么"。

```bash
python scripts/intel.py --persona executive --track T001,T006 --limit 20
python scripts/intel.py --keyword 宁德时代,CATL,曾毓群    # 盯一个对手
```

### 三、个体投资者

**痛**：噪音太多；追高被套；分不清事实与叙事。

**给你**：**事实 / 叙事 / 推断**三分，加"值得关注"与"需要警惕"两栏。
条数本身也是热度信号——同一赛道当天有几条过线新闻，说明市场注意力在哪。

```bash
python scripts/intel.py --persona investor --sector 信息技术 --limit 15
```

> ⚠️ **不给买卖建议、不给目标价、不预测涨跌。**
> 评分衡量的是**新闻重要性**，不是标的收益率。以下永远只是信息整理。

### 四、行业研究人员

**痛**：分类口径不可比；数据不可追溯；只能看到快照，看不到演变。

**给你**：表格 + 全部字段（编号/分类/评分/来源/时间/原文），**不删低分条目**，
并说明样本口径与局限。编号稳定，可做时间序列。

```bash
python scripts/intel.py --persona analyst --sector 能源 --format json > d.json
python scripts/render.py --input d.json --out brief.html --group-by cat_code
```

### 五、科研人员

**痛**：技术新闻与产业化脱节；不知道谁在做；政策资金信号分散。

**给你**：按**技术成熟度**分层（原理验证 / 中试样机 / 小批量量产 / 规模量产），
每条标"距产业化还差什么"，并附政策与资金信号。

```bash
python scripts/intel.py --persona researcher --sector 医疗保健 --keyword 基因治疗,ADC
```

## 五种输出形态

1. **速览** —— 5 条，每条一句话，碎片时间看
2. **标准简报** —— 15 条，按板块分组，含摘要与"值得关注"
3. **单条深挖** —— 发生了什么 / 关键信息 / 背景 / 影响 / 后续可关注
4. **增量模式** —— 只讲相比上次新增了什么
5. **可分享 HTML 日报** —— 自包含单文件，无外部依赖，可直接转发或归档

## 安装与使用

```bash
# 1. 自检（首次必跑）
python scripts/intel.py --check

# 2. 摸底：今天什么最重要
python scripts/intel.py --top --limit 10

# 3. 按你的关注取数
python scripts/intel.py --sector 信息技术 --limit 15

# 4. 记住你的关注范围，以后不传参就用它
python scripts/intel.py --save-sector 信息技术,能源
```

**依赖**：零依赖。脚本只用 Python 标准库（3.7+），不需要 pip install。
**纯提示词也能用**：任何支持 HTTP 的智能体直接读
`https://tekoai.net/index.json` 与对应 feed，流程完全一致。

跨平台注意：Windows 用 `python`，macOS/Linux 多用 `python3`。
首次先探测：`python3 --version || python --version || py --version`。

## 三条红线

1. **不编造**——数据源不可达就如实说，绝不凭记忆写新闻
2. **不夸大来源**——有 5,000 个采集源就说 5,000 个，不吹成"全网"
3. **不把模型判断说成原始事实**——评分与分类是模型给的，事实请以原文为准
